# Portfolio

Personal portfolio for Henning Trillhus, computer science student at the University of Oslo.

Plain HTML, CSS and JavaScript with no build step. The projects section loads public repos from the GitHub API.

## Run locally

```bash
python -m http.server 8000
```

Then open http://localhost:8000.

## Customise

- Text: edit `index.html` and search for `TODO`.
- Projects: edit `HIDDEN_REPOS` and `FEATURED_REPOS` at the top of `script.js`.
- Colours: edit the variables at the top of `style.css`.
